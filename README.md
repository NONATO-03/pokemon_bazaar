# Bazar de Monstros

Auto-batalha de cartas no navegador: compre monstros, monte o tabuleiro e vença 10 batalhas.

Abra `index.html` no navegador (sem instalação, sem dependências).

- `game.js`: regras, simulação da batalha e interface
- `art.js`: ilustrações originais das criaturas, cenários, retratos e ícones, geradas em SVG
- `style.css`: visual
